怎样理解探测结果？

请求强度读取请求报文中的 reasoning.effort 或 reasoning_effort；配置文件里的默认值仅作参考。

最终回显取 response.completed 等结束事件或完整 JSON 的字段。首包有值而最终没有值，仍显示“未回显”。显式 null 与字段缺失分开显示。

返回模型是响应声明的名称，可能存在别名；无法单靠它证明远端真实模型。

覆盖范围支持 HTTP JSON、SSE，以及未压缩的 Responses WebSocket 文本消息。压缩 WebSocket 透明转发，但标为无法解析；CCSwitch 内部出站改写不可见。

停止与恢复“恢复地址”保留服务继续转发；“恢复并停止”等待当前请求完成。已有 Codex 进程可能缓存地址，请在恢复后重新启动 Codex。关闭本网页不会停止后台服务。
