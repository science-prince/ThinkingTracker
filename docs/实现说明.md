# 实现说明

## 模块

| 文件 | 责任 |
| --- | --- |
| `src/main.mjs` | 生命周期、本机令牌控制接口、发现 / 接入 / 恢复、演示 |
| `src/proxy.mjs` | HTTP 流式转发、响应观察分支、透明 WebSocket 隧道 |
| `src/evidence.mjs` | 白名单元数据提取、JSON / SSE 解析、证据状态与比较 |
| `src/ws_inspector.mjs` | 被动解析未压缩 WebSocket 文本帧，支持掩码和分片 |
| `src/config_bridge.py` | selfcontrol Python 标准库 TOML 解析、字段替换、只读 SQLite |
| `src/store.mjs` | 有界元数据历史及串行原子保存 |
| `public/` | 无框架、无 CDN 的中文面板，使用 textContent 展示服务端字段 |
| `launch.ps1` / CMD 入口 | Windows 后台启动、已有实例复用和恢复 |
| `tests/` | 协议、转发、恢复和 Windows 启动器的模拟测试 |

不依赖第三方 npm / Python 库。Node 至少 22；当前 Windows 上以 Node 24.14.0、Python 3.12.12 验证。启动器使用 Windows PowerShell 5.1，含中文的 PS1 保存为 UTF-8 BOM，避免旧 PowerShell 的编码误读。

## 数据处理

只提取预先列出的字段：`model`、`reasoning.effort`、`reasoning_effort`、`output_config.effort`、用量中的数字字段，以及有限的 thinking 模式 / 预算补充字段。不递归搜索输入、工具结果、文本或 metadata 中的同名字段，避免把提示词中的 JSON 当作协议证据。

SSE 按 UTF-8 增量解码、按空行完成事件，兼容 CRLF、多行 data 和 `[DONE]`。Responses 使用 `response.completed`、`response.failed`、`response.incomplete` 等终止事件；Chat Completions 保留结束 chunk 的回显，以随后用量 chunk 补充 tokens，不能把初始 chunk 回显复制成最终回显。孤立的 `[DONE]` 不能证明 Responses 正常结束。

字段缺失、null、未知字符串、冲突与错误类型分别保留。过长或需脱敏的字符串不能用于“精确相同”比较，避免截断后产生假一致。0 tokens 不做布尔过滤。模型字符串与强度字段分别处理；不据用量推断强度。

HTTP 应用正文不被改写。Node 会重新生成 HTTP 分块等传输框架，并按规范去除逐跳头、重设 Host；这不等于 TCP 报文逐字节相同。响应压缩只在观察分支解码，交付给 Codex 的压缩正文保持原样。观察分支失败不能修改响应或触发重试。绝对请求目标、浏览器跨站请求和代理循环会被拒绝。

WebSocket 握手与帧字节直接在两端 socket 之间转发。观察分支只在完整文本消息时解析 JSON，不改掩码、分片或压缩协商。暂不解压 permessage-deflate；压缩和二进制消息明确告警。顺序请求可以逐条记录；未能证明关联的重叠请求标记 `association_ambiguous`，不配对猜测。

## 生命周期和配置事务

启动顺序：只读发现 → 绑定代理端口 → 绑定面板端口 → 保存运行实例 → 可选接入。绑定失败不写 Codex 配置。实际接入前先确认 CCSwitch 本机 TCP 端口监听；不发送远端健康或模型请求。

接入先写不含密钥的字段恢复意图，再对配置做比较后原子替换。若崩溃发生在恢复记录保存后、配置改写前，恢复会发现字段仍是原值并跳过。重复接入不把探测器地址备份为上游。恢复同样检查当前文件、只改仍属于本工具的地址，并清空已处理的恢复记录。

原子替换不等于与外部写入进程共用锁：保存前两次内容检查可以发现变化，但与其他程序在最后 rename 附近极短时间内竞态的风险仍存在。因此需要在接入 / 恢复瞬间避免同时编辑配置；程序不会自动每秒抢写。程序尚未覆盖内联 TOML 表、独立 profile 文件或运行时地址覆盖。

停止先恢复，失败则保留服务运行；成功后等待已有请求结束，再关闭监听和空闲 WebSocket。面板关闭与服务停止分开。强制关机 / 进程被外部杀死时无法保证自动恢复，`recovery.json` 和独立紧急恢复入口处理该情形。

## 安全与证据限制

面板控制接口需随机 256 位令牌，并验证 Host / Origin / Sec-Fetch-Site；所有监听固定为 IPv4 回环地址。令牌通过浏览器 fragment 进入页面，在 sessionStorage 保留、从地址栏移除；不进入普通 HTTP 查询参数或服务日志。响应添加 CSP、no-store 和禁止嵌入策略。页面使用 DOM 文本节点，服务端字符串不会变成 HTML。

SQLite 使用 `mode=ro` 与 `PRAGMA query_only=ON`，且只选择代理配置和供应商名称列，不选择供应商的认证配置。Python 连接显式关闭，避免 Windows 文件句柄残留。配置处理不读取 `auth.json`；读到的完整 TOML 仅在内存中用于保留未修改设置。

元数据文件有条数上限，保存串行化并在同目录使用临时文件再 rename；损坏历史不会自动覆盖。测试产生的临时配置、数据库、代码副本、日志和截图全部位于本项目目录。测试删除前验证绝对路径位于 `test-output` 内。

本工具无法证明“真实思考强度”，也不能核验服务商是否伪造回显。能做的核验是**观测点上的请求值与最终响应声明值是否一致**。来源名和模型名也是声明；CCSwitch 内部重写、故障转移和远端隐藏路由不可见。
